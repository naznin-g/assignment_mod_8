Apphub
A simple and interactive React app gallery that displays a collection of apps, allows users to install/uninstall apps, and view detailed app information.
Built with React Router, Tailwind CSS, and DaisyUI for smooth navigation and a clean UI

Features

Browse all apps with live search filtering.

View detailed app information (downloads, ratings, size, company info).

Install and uninstall apps with persistent local storage.

Rating breakdown chart using Recharts.

Responsive design built with Tailwind CSS.

Routing and data loading handled by React Router (v6).


Tech Stack

Frontend: React, React Router

Styling: Tailwind CSS, DaisyUI

Charts: Recharts

Notifications: React Toastify

Storage: LocalStorage API
